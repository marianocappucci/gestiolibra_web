Servicios y recursos

El catálogo de Gestiolibra tiene dos piezas: el recurso que atiende y el servicio que se ofrece.

Recursos

Un recurso es lo que efectivamente "recibe" un turno: un profesional, un box, una máquina de lavado, un elevador de taller. Cada recurso pertenece a una sucursal y tiene su propia disponibilidad.

Andá a Recursos → Nuevo recurso, elegí la sucursal y ponele un nombre identificable (por ejemplo, "Box 2" o el nombre del profesional).

Servicios

Un servicio define qué se ofrece: nombre, duración y qué recurso lo puede brindar. Se carga en Servicios → Nuevo servicio.

Precio por sucursal

El precio de un servicio se configura por sucursal, no como un campo único del servicio — un mismo corte de pelo puede costar distinto en cada local. Esto se carga en Servicios → (elegir servicio) → Precios.

Tip: si todavía no facturás (plan Básico), el precio igual sirve como referencia para saber cuánto cobrar al completar el turno.

Relación con la agenda

Al reservar un turno se elige primero el servicio, y el sistema filtra los recursos que pueden brindarlo. Ver Agenda y turnos.
