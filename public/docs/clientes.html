Clientes

Ficha de contacto simple, con historial de turnos y — si facturás — datos fiscales.

Alta de un cliente

Podés cargar un cliente por adelantado desde Clientes → Nuevo cliente, o directamente al reservar un turno nuevo sin salir de la agenda.

Datos fiscales (Premium)

Si tenés el plan Premium con facturación activa, cada cliente puede tener CUIT y condición de IVA — se usan para decidir si la factura emitida es tipo A o B. Sin estos datos, se factura igual como Consumidor Final.

Historial

Desde la ficha del cliente vas a ver todos sus turnos pasados y futuros, para tener contexto rápido sin buscar en la agenda general.
